# Terminology Notes

面向高考语文议论文写作的人文社科专业术语素材库。

这个仓库用于积累适合高中生理解、适合考场议论文使用的学术概念、理论效应和思辨名词。内容重点不是堆砌“高级词”，而是把心理学、社会学、哲学、传播学、统计学等领域中的可迁移概念，转化为能服务作文立意、分论点展开和现象分析的论据素材。

## 项目定位

高考作文想写出思辨深度，关键不只是语言漂亮，还要能解释现象、分析原因、提炼价值。这个仓库收录的术语，主要服务以下写作场景：

- 青年成长、自我反思、情绪修养
- 社会现象、公共秩序、规则底线
- 科技发展、媒介信息、算法推荐
- 个体与集体、责任担当、实干理想
- 文化传承、求真精神、理性判断

每个词条都尽量做到三点：概念准确、表达通俗、考场可用。

## 收录原则

本仓库优先收录能提升议论文分析层次的专业术语，例如：

- 心理学效应：用于分析个体认知、情绪、选择与成长。
- 社会学理论：用于分析社会秩序、群体行为与公共生活。
- 哲学概念：用于提升立意高度，连接价值判断与人生选择。
- 传播学概念：用于分析媒介环境、信息传播与公众注意力。
- 统计学思维：用于辨析偏差、概率、样本与理性判断。

不收录普通成语、诗词摘抄、泛泛好词、口号式金句或考场中难以自然使用的冷僻理论。

## 文件结构

每个术语独立保存为一个 Markdown 文件，文件名即术语名，例如：

```text
认知失调.md
破窗效应.md
格物致知.md
议程设置.md
```

词条内容统一包含：

1. 名词基础信息
2. 完整释义
3. 高考适配写作话题
4. 高考范文标准案例
5. 加分写作提示

这种结构便于直接背诵、分类复习，也方便在写作训练时快速检索可用论据。

## 使用方法

### 1. 按作文主题检索

写作前可先确定材料主题，再选择对应术语。例如：

- 写“面对错误与成长”时，可使用“认知失调”分析自我辩解与理性修正。
- 写“规则与秩序”时，可使用“破窗效应”分析小失范如何影响大环境。
- 写“求真与实践”时，可使用“格物致知”连接传统智慧与现实行动。
- 写“信息时代的判断力”时，可使用“议程设置”分析热点、媒介与注意力。

### 2. 放在分论点开头

术语最适合放在分论点开头，用作道理论据，然后自然过渡到材料分析。

示例：

> 传播学中的“议程设置”说明，媒介反复呈现什么，公众便更容易关注什么。青年身处信息洪流之中，不能只追随热点的流向，更要在主动辨析中守住独立判断。

### 3. 避免生硬堆砌

使用专业术语时，不要只写出名词本身。更重要的是说明：

- 它解释了什么现象；
- 它揭示了什么问题；
- 它能推出什么价值观点；
- 它如何服务作文材料和中心论点。

## 更新计划

本仓库将持续补充适合高考作文的人文社科术语，尽量轮换不同学科方向，避免词条重复与主题单一。每个新词条都会保持统一格式，方便长期积累和考前复习。

- 希望提升议论文思辨深度的学生

- 想建立主题化论据库的写作者

## 说明

本仓库内容以高考议论文写作为应用目标，表达会尽量贴近高中生理解水平。部分学术概念在原领域中有更复杂的讨论，这里会保留核心含义，重点转化为考场可用的写作素材。
