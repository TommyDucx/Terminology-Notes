# 真题专项 · 索引与用法

> **本文件夹定位**：把 `06-近年真题与标杆作文（广东卷·深圳模考）.md` 中收录的每一道真题，按**标准模板**独立展开成篇。模板结构统一为：
>
> 一、作文题目（原题还原） → 二、破题分析 → 三、板块搭建（立意方向） → 四、思辨讲深 → 五、角度支架（课内诸子关联 + 论据） → 六、真题链接（相关题） → 七、示范例文
>
> **用法**：先读本索引选题，再点开对应文件做"一题一练"。每篇都可直接当备课/备考讲义用。
