# 诸子思想 · 写作迁移与立意思路

> 本文件解决：**把课本里的诸子金句，变成考场作文的"角度、立意、素材"**。
> 对应任务要求 ③ 提供可迁移的写作角度与立意思路，并注明适用情境。

---

## 一、按主题归类的可迁移角度

### 1. 青年修身 · 自我成长
- **自胜者强**（老子）：真正的强大是战胜自己，而非胜过他人。
- **弘毅任重**（论语）：青年须有远大志向与坚韧意志。
- **扩而充之**（孟子）：善端如星火，须主动培养放大。
- **文质彬彬**（孔子）：反对"空心精致"或"粗野无文"，追求表里如一。

### 2. 坚持 · 积累 · 量变到质变
- **千里之行，始于足下 / 为山九仞，功亏一篑 / 慎终如始**：适用于"半途而废""厚积薄发""善始善终"。

### 3. 辩证思维（二元 / 转化）
- **有无相生**：留白、虚实的互补。
- **自知与知人、自胜与胜人**：向内看比向外争更高明。
- **有用与无用**：功利尺度之外的价值。

### 4. 社会责任 · 家国担当
- **修齐治平 / 弘毅任重 / 张载四句**：适用于"青年与时代""个人与家国"。
- **兼相爱则治**（墨家）：可对接"人类命运共同体""合作共赢"。

### 5. 尊重规律 · 人与自然
- **道法自然 / 辅万物之自然而不敢为**：生态文明、绿色发展、不揠苗助长。
- **为之于未有，治之于未乱**：预判、风控、未雨绸缪。

### 6. 包容 · 换位思考 · 和谐
- **己所不欲，勿施于人**：网络文明、尊重差异。
- **兼相爱**：化解对立、合作共赢。

## 二、立意思路升维（怎么把"用典"变成"立意"）

- **路径 A：小概念 → 大关怀**：从"自省"上升到"社会互信"，从"慎终如始"上升到"民族复兴须久久为功"。
- **路径 B：正反对举**：有用 / 无用、有为 / 无为、仁爱 / 兼爱——用对立张力撑开文章骨架。
- **路径 C：儒道互补**（最推荐写"青年安身立命"）：儒家教"拿得起"（担当），道家教"想得开"（超脱）。例：以儒家之志立业，以道家之慧养心，方能在内卷时代既不躺平也不崩塌。
- **路径 D：以古证今**：用诸子智慧回应当代问题——内卷（无用之用）、功利主义（文质彬彬）、生态危机（道法自然）、网络戾气（兼相爱）。

## 五、两个完整立意骨架（可直接套用）

**示例一｜以"无用之用"破"功利焦虑"**
- 起：当下教育 / 社会唯"有用"是图，哲学、艺术、慢思考常被贬为"无用"。
- 承：引庄子"五石之瓠"与"无用之用"——大葫芦系腰为樽可浮江湖，恰是世俗眼中的"无用"成就了大用。
- 转：老子"有之以为利，无之以为用"补证：留白与虚空才是功能的真正承载。
- 合：青年当为人生留白，不被功利尺度绑架；国家当重"无用之学"，方有精神底气。

**示例二｜以"儒道互补"写青年安身立命**
- 起：时代既召唤青年"拿得起"（担当），又带来普遍焦虑——非此即彼易致崩塌。
- 承：儒家"弘毅""修齐治平"立其志，教人入世有为。
- 转：道家"自知自胜""无用之用"养其心，教人在竞争中安顿自我、不被功利吞没。
- 合：以儒为骨、以道为息，方能既不负时代、亦不负己身。
