# 墨家 · 思想讲解与考场思维引导

> **本文件用法**：每一节先讲清一种墨家思想的**内核**与**课内原典/素材**，再用「发散性思维引导」把它拆成可下锅的考场“配方”——告诉你这种思想**会怎么考**、**从哪里切**、**论点怎么立**、**文章怎么搭**。墨家最擅长写**合作共赢、换位思考、和平反战、共同体意识、务实利他**类作文，且“兼爱 vs 仁爱”是极佳的思辨素材。

## 流派速览

- **代表人物**：墨子（墨翟），战国初期
- **核心主张（“墨家十论”）**：兼爱、非攻、尚贤、节用、节葬、尚同、非乐、非命、天志、明鬼
- **精神气质**：平民立场、务实功利、重逻辑与实证、兼济天下
- **教材课文**：《兼爱》（《墨子》）
- **与儒家之别**：儒家“仁爱”有亲疏差等（先亲后疏）；墨家“兼爱”无差等（爱人若爱其身）。墨子重“利”，主张“兼相爱、交相利”。

## 一、兼爱：无差等之爱（核心思想）

### 思想内核
墨子认为天下一切纷乱（不孝、不慈、盗贼、攻国）皆**起于“不相爱”**——人人只爱自己、爱其家、爱其国，而亏害他人。若使天下人**“兼相爱，爱人若爱其身”**，则国不攻、家不乱、盗贼无有，天下大治。故“**天下兼相爱则治，交相恶则乱**”。这是一种**突破亲疏、超越身份的普遍关怀**。

### 课内原典 & 论据素材
- **当察乱何自起？起不相爱**——诊断祸乱根源于“互不亲爱”。
- **视人之室若其室，谁窃？视人身若其身，谁贼？**——把别人当自己，恶行自消。
- **若使天下兼相爱，国与国不相攻，家与家不相乱**。
- **故天下兼相爱则治，交相恶则乱**——极佳的二元对照句，可直接用于结尾升华。
- **兼相爱、交相利**——相爱相利并行，利他即利己。

### 发散性思维引导

**1) 考场可能考查的方向 / 主题 / 维度**
- 合作共赢、共同体意识（**人类命运共同体**是高频对接点）
- 换位思考、将心比心、公共精神
- 网络文明：少“交相恶”（戾气、网暴），多“兼相爱”
- 公共危机中的互助（抗疫、救灾、跨地域援助）
- 陌生人社会里的“善意”

**2) 审题切入角度**
- 题干出现 **“他人、社会、合作、互助、冷漠、共同体”** → 用“兼爱 / 兼相爱则治”。
- **切入提醒**：兼爱不是“不分对象滥好”，而是“把对亲友之爱推及他人”。若题目谈“陌生人该不该帮”，用“视人身若其身”立论。
- 与儒家配合：题目若涉及“对亲人的爱 vs 对他人的爱” → 用“兼爱 vs 仁爱”做思辨（见第六节）。

**3) 立意确立方法**
- **根因法**：立“天下之乱，起不相爱——重建关怀，方治其本”。
- **推扩法**：立“爱人若爱其身，则天下可治”——从个人善意推到社会善治。
- **金句法**：直接用“兼相爱则治，交相恶则乱”作论点或结尾。

**4) 可直接套用的构思框架**
- **引**：由材料引出“兼爱”——乱起不相爱，治在兼相爱。
- **承**：墨子诊断“起不相爱”，以“视人身若其身”证普遍关怀之效。
- **转**：当代为何要谈兼爱？陌生人社会的冷漠、网络戾气（交相恶）。
- **联**：人类命运共同体、抗疫互助、志愿精神——兼爱在今天的回响。
- **合**：人人兼相爱，则天下治；以爱破恶，方见大同。

## 二、非攻与和平：反对恃强凌弱

### 思想内核
“非攻”是“兼爱”在国际层面的延伸：反对侵略战争，主张以**对话、义理、实力（守备）**止战，而非以攻伐取利。墨子本人即“非攻”的身体力行者。

### 课内原典 & 论据素材
- 墨家“非攻”主张见于《墨子·非攻》；教材《兼爱》虽未直写“非攻”，但“国与国不相攻”已含其意。
- **墨子止楚攻宋**（《公输》）：闻楚将攻宋，裂裳裹足行十日十夜至郢都，以守城器械与雄辩说服楚王退兵——非攻理念的实践典范。
- **当代对接**：和平共处五项原则、联合国维和、文明对话 vs 文明冲突。

### 发散性思维引导

**1) 考场可能考查的方向 / 主题 / 维度**
- 和平、反战、对话 vs 对抗
- 文明冲突与文明互鉴
- “强者如何待弱者”、国际秩序中的公道
- 用实力止战（墨子既反攻，又重守备）

**2) 审题切入角度**
- 题干谈 **“战争与和平、对抗与对话、强弱关系”** → 用“非攻 / 兼相爱则治”。
- **审题要点**：墨子“非攻”≠“不备战”，而是“反侵略、重守备”。若题目讲“国防”，可立“强而不霸，备而不攻”。

**3) 立意确立方法**
- **止战法**：立“真正的强大，是以理与备止战，而非以攻取利”。
- **对话法**：立“以对话代对抗，以兼爱消攻伐”。

**4) 可直接套用的构思框架**
- **引**：材料 + “非攻——反侵略而重守备”的论点。
- **承**：墨子止楚攻宋，以智与守备践行非攻。
- **转**：历史上恃强攻伐的教训 / 今日对抗之害。
- **合**：兼相爱则无攻，对话方致久和平。

## 三、尚贤与节用：平民的务实功利

### 思想内核
墨家站在平民立场：**“尚贤”**——不论出身，唯才是举；**“节用”**——反对奢靡，主张实用、节俭。二者合起来是一种**重实效、反浪费、讲平等**的务实精神。

### 课内原典 & 论据素材
- **尚贤**：墨子主张“官无常贵，民无终贱，有能则举之”。
- **节用 / 节葬**：反对厚葬久丧与奢靡，主张“去无用之费”。
- **当代对接**：选拔任人唯贤、反对形式主义与铺张、绿色低碳（节用即可持续）、“工匠精神”（务实）。

### 发散性思维引导

**1) 考场可能考查的方向 / 主题 / 维度**
- 人才观、平等机会、“英雄不问出处”
- 勤俭节约、反对奢靡、绿色低碳（节用 = 可持续）
- 形式主义、铺张浪费的批判
- 实干 vs 空谈

**2) 审题切入角度**
- 题干谈 **“人才、平等、节约、务实、反浪费”** → 用“尚贤 / 节用”。
- **切入提醒**：把“节用”与现代“可持续 / 低碳”对接，是让古思想“活”在当下的关键。

**3) 立意确立方法**
- **唯才法**：立“官无常贵，民无终贱——唯贤是举方兴邦”。
- **节用法**：立“节用非吝啬，而是对资源的敬畏与可持续”。

**4) 可直接套用的构思框架**
- **引**：材料 + “尚贤节用，务实兴邦”的论点。
- **承**：墨子“官无常贵，有能则举”“去无用之费”。
- **转**：当下浪费、唯出身论的反面。
- **合**：尚贤以聚才，节用以守恒，务实而致远。

## 四、兼相爱、交相利：利他即利己

### 思想内核
墨家不讳言“利”，但主张**“兼相爱、交相利”**——爱人与利人相统一，最终利他亦利己。这把道德（爱）与效用（利）结合起来，是一种**互惠共赢**的伦理。

### 课内原典 & 论据素材
- **兼相爱、交相利**（墨家标志性并提）。
- **“兴天下之利”**是墨家一切主张的落脚点——利，指“天下之人皆得其所”的公利。
- **当代对接**：公益慈善、共享经济、企业社会责任（ESG）、“利他”商业模式。

### 发散性思维引导

**1) 考场可能考查的方向 / 主题 / 维度**
- 合作共赢、利他经济、公益
- “利己与利他”的二元思辨
- 企业 / 个人的社会责任
- 共享、互助型社会

**2) 审题切入角度**
- 题干谈 **“合作、共赢、公益、社会责任、利他与利己”** → 用“交相利”。
- **审题要点**：这类题常是“利己 vs 利他”二元思辨，墨家给的答案是**“交相利”——利他终将利己**，不是否定利己，而是把二者统一。

**3) 立意确立方法**
- **统一法**：立“兼相爱、交相利——利他非损己，而是共赢”。
- **升华法**：立“兴天下之利，方为大利”。

**4) 可直接套用的构思框架**
- **引**：材料 + “交相利，则两利”的论点。
- **承**：墨子以“兼相爱、交相利”统一道德与效用。
- **转**：当下零和思维（损人利己）的局限。
- **合**：以爱促利，以利成爱，社会乃共荣。

## 五、思辨点睛：兼爱 vs 仁爱（儒家对照）

### 思想内核
| 维度 | 儒家“仁爱” | 墨家“兼爱” |
|---|---|---|
| 爱有差等？ | 有（先亲后疏，推己及人） | 无（爱人若爱其身，一视同仁） |
| 逻辑起点 | 血缘亲情 → 推扩 | 普遍平等 → 直接施与 |
| 是否言“利” | 罕言利，重义 | 明言“交相利” |
| 精神气质 | 温厚、秩序 | 刚直、平等、务实 |

### 考场用法
- **二元思辨题**中出现“对亲人的爱 vs 对他人的爱”“私爱 vs 公义” → 用这组对照。
- **立论示范**：面对公共危机，既要有对亲友的“私爱”（儒家仁爱之实），更需对陌生人的“兼爱”（墨家超越之差等）——二者互补，先立己之爱，再扩兼爱之怀。
- **注意**：不要简单说“墨家比儒家好”，而要落到“差序之爱是基础，普遍之爱是升华”。
