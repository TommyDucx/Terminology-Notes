## 三、观点 → 常见作文主题 速查

- **青年担当 / 立志** → 弘毅任重、修齐治平、张载"横渠四句"
- **义利之辨 / 功利主义** → 君子喻于义、无用之用、文质彬彬
- **自省 / 修身** → 见贤思齐、克己复礼、自胜者强
- **坚持 / 积累 / 半途而废** → 千里之行始于足下、为山九仞、慎终如始
- **辩证思维（转化 / 互补）** → 有无相生、自知与知人、有用与无用
- **善良 / 人性** → 四端说、扩充善端、不忍人之心
- **包容 / 和谐 / 换位思考** → 己所不欲勿施于人、兼相爱
- **生态文明 / 尊重规律** → 道法自然（课外补充）、辅万物之自然、为之于未有
- **低调谦逊 / 拒绝浮夸** → 自见者不明、自伐者无功
